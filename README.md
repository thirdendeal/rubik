# Rubik

Ruby API brought to Lua

## Install

Install [middleclass](https://luarocks.org/modules/kikito/middleclass) and [inspect](https://luarocks.org/modules/kikito/inspect)

    luarocks install middleclass
    luarocks install inspect

## Testing

Install [busted](https://luarocks.org/modules/lunarmodules/busted)

    luarocks install busted

Run

    busted
